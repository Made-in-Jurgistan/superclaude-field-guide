Flags

Small switches you add to the end of any command.
Behaviour modes
  • --brainstormAsk questions first, assume nothing
  • --introspectShow the reasoning behind each decision
  • --task-manageBreak into phases and track progress
  • --orchestrateChoose tools carefully, run independent steps in parallel
  • --token-efficientCompressed replies, 30–50% fewer tokens
Tool switches: on
  • --c7 / --context7Official documentation lookup
  • --seq / --sequentialStructured multi-step reasoning
  • --magicUI component generation
  • --morph / --morphllmFast pattern edits across files
  • --serenaMeaning-aware code tools and memory
  • --play / --playwrightReal-browser testing
Tool switches: more
  • --chrome / --devtoolsLive page profiling
  • --tavilyWeb search
  • --frontend-verifyPlaywright + DevTools + Serena together
  • --all-mcpEvery tool at once
  • --no-mcpNo external tools; built-ins and web search only
Thinking depth
  • --thinkStandard structured analysis, about 4K tokens. Adds Sequential
  • --think-hardDeep analysis, about 10K tokens. Adds Sequential and Context7
  • --ultrathinkMaximum depth, about 32K tokens. Adds every tool
Execution control
  • --delegateSplit work across parallel sub-agents
  • --concurrencyCap how many things run at once
  • --loopRepeat improve-and-check cycles
  • --iterationsSet the number of cycles
  • --validateAssess risk before acting
  • --safe-modeMost cautious execution; also turns on --uc
Output and focus
  • --uc / --ultracompressedSymbol-based, very short replies
  • --scopeHow wide to look
  • --focusOne area of concern

Power combos

Fast, targeted command sequences for everyday situations.
P1WebPower

Dark mode and theming

Add a light and dark theme that switches cleanly and keeps text readable in both.
  1. /sc:design themes --type component --format spec "light + dark colour tokens, contrast, user preference" # theme plan
  2. /sc:implement "theme tokens + light/dark switcher" --type component --magic --c7 --with-tests # build it
  3. /sc:improve src --type style --morph "replace hard-coded colours with theme tokens" # apply everywhere
  4. /sc:test --type e2e --frontend-verify # check both themes
P2WebPower

Accessibility compliance sweep

Make sure people who use screen readers or only a keyboard can use your site.
  1. /sc:analyze src --focus quality --depth deep "WCAG 2.1 AA: contrast, labels, focus, keyboard" # issues
  2. /sc:improve src --type quality --focus accessibility --interactive # fixes
  3. /sc:test --type e2e --play # browser checks
